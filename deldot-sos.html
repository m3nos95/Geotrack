DelDOT Approved Product Lists are public PDFs (tack coat, pavement marking, crack seal, curing, TTC, …). This app ships a snapshot and re-checks it when you run refresh-sos-lists.bat. Aggregate pits move on and off the Approved Source List constantly. On the office PC, refresh-sos-lists.bat (daily) and watch-sos-inbox.bat pull \\DOTFS01\Groups\Geo Construction Test Report\Reference Samples\Approved Source List.xlsx. Chrome cannot open that folder from this HTML file. Use Pull chart from office share while start-sos.bat is running (that helper reads the share), or drop the .xlsx here. The Source of Supply Database (Standard Items / Special Provisions) is the official item catalog — drop that .xlsx here so spec numbers pick up the Department description and acceptance method.
