DelDOT BoreLog — Consultant Quick Guide

For geotechnical consultants performing borings for DelDOT Materials & Research Lab

1. Open BoreLog

  • DelDOT staff open BoreLog from LabTrak → Soil Lab hub → DelDOT BoreLog.
  • Direct link (same site): docs/r18-reference/deldot-borelog.html
  • Use the same Supabase URL and anon key as LabTrak (Settings in LabTrak if not already configured).

2. Create project & borings

  1. + NEW PROJECT — enter contract #, project name, location.
  2. Open the project → + NEW BORING or import a GeoSystem .GEO folder.
  3. On each boring header, enter Northing/Easting or capture GPS so locations appear on LabTrak maps.

3. Log samples

  • Add samples with depths, blows, and lab data in BoreLog.
  • Set each sample lab status: Awaiting drop-off → Received → In lab → Complete.
  • Print DROP-OFF sheet from the boring screen when delivering physical samples to the lab.

4. Sync to DelDOT cloud

  1. Click ☁ SYNC after saving work.
  2. Chip should show CLOUD when connected. If it says NO TABLE, ask DelDOT to run the borelog Supabase migration.
  3. DelDOT lab sees incoming samples on the Soil Lab hub → Incoming BoreLog Samples panel after sync.
Important: BoreLog samples are not field-control samples. They exist only after you create the boring in BoreLog. Physical drop-off at the lab should match the printed drop-off sheet.

5. Support

Contact DelDOT Materials & Research Lab for contract assignment, LabTrak access, or sync issues.
